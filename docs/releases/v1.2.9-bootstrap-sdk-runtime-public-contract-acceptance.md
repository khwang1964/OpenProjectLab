## Accepted scope

The Design First contract for `generator.sdk.bootstrap_runtime` is terminally accepted.
It defines a typed, immutable, deterministic, and silent SDK adapter over the existing
core bootstrap runtime while preserving existing generator/plugin SDK exports.

CLI and SDK remain sibling adapters. The SDK owns no argument parsing, stream rendering,
or process exit-code policy. Preview and validation remain inspection-only; apply remains
the sole filesystem mutation boundary. Repair, rollback, and hidden retry remain forbidden.
