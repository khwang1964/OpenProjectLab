# v1.3.11-v1.3.13 Verification Report Usability Design Train

> Status: Design Accepted / Completed

## Train scope

- v1.3.11 — canonical serialization of the accepted immutable verification report
- v1.3.12 — deterministic offline report validation and inspection
- v1.3.13 — stable machine-readable result and exit-code contract

## Dependency order

v1.3.11 defines canonical report documents. v1.3.12 composes strict decoding and
offline inspection without runtime authority. v1.3.13 exposes those accepted report
operations through the existing stable additive CLI family.

## Delivery plan

The adjacent capabilities share one Design PR, one terminal Design Acceptance PR,
one implementation PR, one terminal-alignment PR, and one separate implementation
acceptance closure PR. Every merge remains explicitly authorized.

## Deferred authority

- production implementation is Not Started for every slice
- stdin, file output, batch, queue, watch, retry, polling, and scheduling are deferred
- SDK, network services, plugins, credentials, mutation, release, and publication are
  deferred
- arbitrary subprocess and test execution remain prohibited

## Code Review Checklist

- [ ] Architecture, release, governance, and contract tests use exact train markers.
- [ ] Canonical output and strict decoding rules agree.
- [ ] Offline inspection remains stateless and runtime-free.
- [ ] Stable exit categories remain deterministic and platform-independent.
- [ ] Existing stable CLI commands remain compatible.
- [ ] Production implementation remains Not Started.
