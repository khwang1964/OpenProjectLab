## Accepted production capability

The minimum `generator.sdk.bootstrap_serialization` implementation is accepted with the
`opl.bootstrap/1.0` closed envelope, canonical UTF-8 JSON, deterministic request/result
and evidence round-trip, forward-slash lexical paths, strict fail-closed decoding, and
non-executing deserialization.
