configuration.

are not part of the v1.0 maintained support commitment unless separate
evidence is added.

## 6. Known-Limitation Governance

The published register covers, at minimum:

- environment-support boundaries;
- live-provider AI operational dependence;
- remote Marketplace deferral;
- Plugin distribution / dependency / trust deferrals;
- grading and scoring runtime deferral;
- Slides renderer limitations;
- Website hosting / deployment limitations;
- lack of generalized cross-Generator rollback;
- exact error-text compatibility boundary;
- Internal module API boundary;
- built-artifact versus editable/source-checkout boundary;
- deterministic core-CI network independence;
- EN / zh-TW formal documentation-language boundary;
- Step 8.8 ownership of release automation and reproducibility.

Each published Known Limitation carries impact and mitigation/workaround
information through the canonical register.
