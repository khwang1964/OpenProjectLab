# OpenProjectLab Code of Conduct

## Our Pledge

We are committed to making participation in OpenProjectLab a welcoming, respectful, and inclusive experience for everyone.

Regardless of experience level, nationality, language, gender, disability, age, religion, or background, everyone should feel safe contributing to this project.

---

## Our Standards

Examples of positive behavior include:

* Being respectful and professional
* Giving constructive feedback
* Helping newcomers learn
* Respecting different opinions
* Using inclusive language
* Focusing discussions on technical issues
* Accepting responsibility for mistakes
* Collaborating in good faith

Examples of unacceptable behavior include:

* Harassment
* Personal attacks
* Hate speech
* Discrimination
* Threats
* Deliberate disruption
* Publishing private information
* Trolling or inflammatory comments

---

## Project Philosophy

OpenProjectLab is built upon three principles:

* **Design First**
* **Documentation First**
* **Automation First**

Contributors are expected to:

* Write maintainable code.
* Include documentation for new features.
* Add or update tests.
* Follow project coding standards.
* Respect code review feedback.

---

## Communication

Please keep discussions:

* Respectful
* Technical
* Evidence-based
* Solution-oriented

Healthy disagreement is welcome.

Personal attacks are not.

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may:

* Request changes
* Remove inappropriate content
* Reject pull requests
* Temporarily restrict participation
* Permanently ban users in severe cases

Enforcement decisions will be made fairly and consistently.

---

## Reporting Issues

If you experience unacceptable behavior, please contact the project maintainers.

Reports will be handled confidentially whenever possible.
