## Existing boundaries

| Command | Service | Method |
| --- | --- | --- |
| course | AICourseGenerationService | generate_course(request) |
| review | AIReviewService | review(request) |
| document | AIDocumentationService | generate(request) |
| template | AITemplateCompletionService | complete(request) |

The existing services and mappers remain authoritative. CLI code must not
duplicate mapping. The proposed production module is generator/cli/ai.py, but
it is not created or registered in this slice.

Production code must not import FakeAIProvider. The stable local-response path
requires a production-local deterministic provider boundary. Live-provider
resolution remains Experimental and explicitly opted in. There is no implicit
provider, credential lookup, network fallback, or interactive prompt.

Validation completes before provider invocation or success output. Failures
use exit 2, diagnostics go to stderr, and emit no success document on stdout.
The AI CLI does not mutate the filesystem, repository, registries, manifests,
Marketplace state, or generated projects.
