## 4. Scope Accepted for Review

Planning acceptance covers only:

- Operational CLI Expansion as the proposed v1.1 theme;
- additive Marketplace CLI planning over deterministic local contracts;
- additive AI CLI planning over provider-independent contracts;
- preservation of the v1.0 Stable subset;
- explicit Deferred/non-goal boundaries;
- EN/zh-TW parity and artifact-backed verification as required gates;
- the delivery ordering recorded in the governing baseline.

It does not accept any Marketplace CLI or AI CLI implementation.

## 5. Preserved Boundaries

The following must remain true throughout closure:

- `v1.0.0` tag and published artifacts remain immutable;
- v1.0 Stable contracts remain compatible;
- Marketplace CLI remains `Not Started`;
- AI CLI remains `Not Started`;
- live provider behavior remains Experimental and opt-in;
- remote Marketplace, activation, signing/trust, dependency resolution,
  ratings/reviews, monetization, streaming/tool calling, and other stated
  non-goals remain Deferred;
- Formal v1.1 Acceptance remains `Not Accepted`.
