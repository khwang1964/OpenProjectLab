# v1.3.2 Repository / GitHub Evidence Adapters — Design Baseline

> Status: Accepted — Terminally Closed

## Predecessor

v1.3.1 Developer / Release Automation minimum implementation is
Accepted / Completed.

## Objective

Define deterministic, read-only repository and GitHub evidence adapters that
collect observations for the existing fail-closed validation core.

This Design First slice does not authorize production implementation until its
design acceptance workflow is terminally completed.

## Proposed boundary

Repository observations include:

- repository identity;
- current branch identity;
- working-tree cleanliness;
- local HEAD and `origin/main` commit identities;
- configured remote identity.

GitHub observations include:

- pull-request number, URL, state, base, and head branches;
- merge commit and merge timestamp when available;
- required-check names, status, and conclusions;
- unknown or unavailable GitHub state as typed collection failure.

Adapters return immutable observation values. They do not modify repository,
GitHub, lifecycle documents, credentials, or release artifacts.

## Dependency direction

Repository and GitHub adapters provide observations to the existing validation
core. The validation core must not invoke adapter write operations.

Provider-specific command execution and response parsing remain behind the
adapter boundary.

## Determinism and failure semantics

- Required checks use stable ordering.
- Missing fields fail closed.
- Unknown GitHub mergeability is not treated as success.
- Collection and parsing failures remain typed and reproducible.
- No planned or future evidence is synthesized.
- No lifecycle document is automatically repaired.

## Explicitly deferred

- automatic pull-request merge;
- force push, reset, or branch deletion;
- tag, GitHub Release, package publication, or artifact upload;
- credential capture or serialization;
- generalized orchestration outside OPL;
- end-user CLI or `generator.sdk` expansion;
- Bootstrap checkpoint/resume;
- serialization schema migration.
