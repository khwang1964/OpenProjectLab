# OpenProjectLab v1.2.6 Bootstrap Runtime Integration

> **Status:** Design / Contract Definition --- In Progress
> **Predecessor:** v1.2.5 Bootstrap Validation Runtime --- Accepted / Implemented
> **Production Implementation:** Not Started

## Purpose

Define deterministic internal coordination of the accepted planning, dry-run,
apply, and validation runtimes without widening Stable CLI or public SDK surfaces.

## Core Contracts

### BootstrapRuntimeMode

The closed modes are `preview`, `apply`, and `apply-and-validate`. Mode selection
is explicit and cannot be changed implicitly by environment or observed state.

### BootstrapRuntimeRequest

Immutable planning intent, generator selection, normalized inputs/effects,
target context, and explicit runtime mode.

### BootstrapRuntimeResult

Immutable authoritative plan and completed-phase evidence. Unexecuted phases
remain explicit `None`, not success-shaped placeholders.

### BootstrapRuntimeCoordinator

`BootstrapRuntimeCoordinator.execute(request)` delegates to accepted runtimes.
It does not duplicate lifecycle, filesystem, validation, or rollback behavior.

## Mode Matrix

``` text
preview --- plan + preview; apply forbidden; validation not run
apply --- plan + apply; validation not run
apply-and-validate --- plan + apply + validation, in that order
```

## Determinism

- planner is invoked exactly once;
- preview and apply receive the same `BootstrapPlan` identity;
- phase ordering is deterministic and sequential;
- equivalent inputs and dependencies produce equivalent results.

## Failure Semantics

``` text
Planning Failure --- Propagated / No Later Phase
Apply Failure --- Propagated / Validation Not Run
Validation Check Failure --- Propagated
Invalid Validation Result --- Completed Result / is_valid False
Success-shaped Partial Result --- Forbidden
```

Invalid validation evidence is distinct from a validation execution failure.
The coordinator must not call apply in preview mode, silently repair, or
initiate automatic rollback.

## Closed Surfaces

``` text
Implicit Network Access --- Forbidden
Implicit Plugin Activation --- Forbidden
Automatic Repair / Rollback --- Forbidden
Checkpoint / Resume --- Deferred
Parallel Runtime Execution --- Deferred
CLI Boundary --- Not Accepted
Public SDK Expansion --- Forbidden
Stable Serialized Result --- Not Accepted
```
