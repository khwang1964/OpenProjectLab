---

## 1. Purpose

GA.4 proves that the actual stable `1.0.0` distribution artifacts satisfy the
installed-user and release-readiness contracts.

GA.3 proves artifact identity.

GA.4 proves artifact behavior.

GA.4 must use the exact GA wheel, sdist, checksum manifest, and approved source
commit. Source-checkout-only success is not acceptable as GA completion
evidence.

---

## 2. Governing Decision

GA.4 is fail-closed.

Completion requires all required artifact inputs and all required artifact-backed
verification layers to pass against the same GA artifact set.

Required identity:

```text
Package version
    1.0.0

GA tag
    v1.0.0

Wheel
    openprojectlab-1.0.0-py3-none-any.whl

sdist
    openprojectlab-1.0.0.tar.gz
```

Required GA artifact-backed skips:

```text
0
```

A missing required input is a failure for GA.4 completion evidence.

---

## 3. Required Artifact Inputs

GA.4 requires:

```text
OPL_TEST_WHEEL
OPL_TEST_DIST_DIR
OPL_TEST_CHECKSUM_MANIFEST
OPL_RELEASE_COMMIT_SHA
```

These values must identify one coherent GA artifact set.

Unlike historical RC tests, GA.4 completion tests must not silently skip when
these inputs are absent.

---

## 4. Exact Distribution Set

`OPL_TEST_DIST_DIR` must contain exactly:

```text
openprojectlab-1.0.0-py3-none-any.whl
openprojectlab-1.0.0.tar.gz
SHA256SUMS.txt
```

The configured wheel must be:

```text
openprojectlab-1.0.0-py3-none-any.whl
```

and must belong to the configured distribution directory.

RC artifacts such as:

```text
openprojectlab-1.0.0rc1-py3-none-any.whl
openprojectlab-1.0.0rc1.tar.gz
```

must not satisfy GA.4.

---

## 5. Checksum Identity

`SHA256SUMS.txt` must exactly cover the GA wheel and sdist.

Required properties:

- exactly one wheel digest;
- exactly one sdist digest;
- no RC artifact entry;
- no extra distribution entry;
- no UTF-8 BOM;
- all digests are lowercase 64-character SHA-256 values;
- recomputed digests match the recorded values.

Checksum mismatch is a GA blocker.

---

## 6. Release-source Commit Binding

`OPL_RELEASE_COMMIT_SHA` must be:

- present;
- a full 40-character lowercase Git SHA;
- the source identity used to build the configured GA artifacts;
- the same source identity used by integrated release verification.

GA.4 does not create the `v1.0.0` tag.

## 10. Non-goals

GA.4 does not:

- create `v1.0.0`;
- push `v1.0.0`;
- create or publish a GitHub Release;
- mutate `v1.0.0-rc.1`;
- formally accept GA;
- replace GA.5 full regression / local quality gates;
- replace GA.6 GitHub Actions / CI.

## 12. Automation Contract

`tests/release_readiness/test_v1_ga_artifact_backed_verification.py` must verify:

- this governing design exists;

- configured wheel belongs to configured dist;
- exact stable wheel/sdist filenames are used;

- checksum manifest exactly matches GA artifact bytes;

- required GA artifact-backed skips are zero;
- GA publication and formal acceptance remain later gates.

## 13. Failure Classification

| Failure | Meaning | Response |
|---|---|---|
| Missing artifact input | GA.4 evidence is incomplete | Fail |
| Wrong wheel | configured wheel is not stable GA | Fail |
| Dist mismatch | stale/extra/missing distribution | Fail |
| Checksum mismatch | artifact bytes differ from manifest | Fail |
| Source SHA invalid | artifact source identity is not immutable | Fail |
| Installed-user failure | GA wheel does not satisfy user contract | Fix |
| Required skip | completion evidence is incomplete | Fail |
| RC/GA confusion | RC artifact supplied to GA gate | Fail |
