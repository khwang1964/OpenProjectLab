## 10. Fail-closed Acceptance Rules

Formal GA Acceptance must remain `Not Accepted` when any GA.8 closure gate is
unresolved.

The following are blockers:

- acceptance PR not merged;
- required PR CI not green;
- local `main` not synchronized with `origin/main`;
- dirty post-merge working tree;
- post-merge consistency test failure;
- stale Roadmap / HISTORY / CHANGELOG terminal state;
- release identity contradiction;
- unresolved acceptance closure marker.

No later passing check may erase an unresolved blocker without explicit
resolution evidence.
