## Accepted production capability

The minimum `generator.sdk.bootstrap_runtime` implementation is accepted as a typed,
immutable, deterministic, and silent Python SDK adapter over the core bootstrap runtime.
Preview, apply, and apply-and-validate are supported. Existing `generator.sdk` root
exports remain compatible, and the SDK remains independent from CLI process semantics.

Usage failures are reported as `BootstrapSdkUsageError`. Runtime and validation-check
execution failures fail closed as `BootstrapSdkExecutionError` with phase, failed identity,
and completed evidence. Validation findings remain normal typed invalid results.
