## 4. Contract Accuracy

The manuals describe the frozen and verified v1.0 product boundary. They do not create a second product contract or promote Experimental, Internal, Deferred, or unimplemented architecture into Stable behavior.

Key boundaries preserved:

- installed-artifact-first installation and Quick Start guidance;
- canonical CLI and Generator workflows;
- Courseware fail-fast semantics without generalized cross-Generator rollback;
- canonical Plugin Entry Point / validation / registry boundary;
- provider-independent AI boundary;
- Marketplace documentation limited to implemented and verified behavior;
- upgrading guidance remains conservative and does not pre-empt Step 8.6 compatibility/deprecation governance.
