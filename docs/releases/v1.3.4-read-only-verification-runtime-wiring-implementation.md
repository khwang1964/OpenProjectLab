# v1.3.4 Read-only Verification Runtime Wiring — Implementation

> Status: Implemented / Awaiting implementation acceptance

## Scope

Implements the accepted internal runtime configuration, exact read-command policy,
deterministic executor, stable process-failure mapping, and component factory.

## Preserved boundaries

- The factory constructs components but never runs verification.
- Only adapter-required Git and GitHub read commands are allowed.
- No CLI, public SDK, arbitrary subprocess, mutation, release, or publication.
- No retry, polling, persistence, caching, telemetry, or credential management.

## Code Review Checklist

- [ ] Configuration is immutable, explicit, validated, and deterministically ordered.
- [ ] Command policy rejects all unknown or mutating commands before execution.
- [ ] Process execution uses argument vectors, explicit cwd and timeout, and no shell.
- [ ] Timeout and OS execution failures map to stable non-zero results.
- [ ] The factory reuses accepted adapters, validator, and orchestrator unchanged.
- [ ] Factory construction performs no command or verification.
- [ ] Unit, release-readiness, pre-commit, full regression, and CI pass.
