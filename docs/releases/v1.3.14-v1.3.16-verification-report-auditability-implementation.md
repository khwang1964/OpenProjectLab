# v1.3.14-v1.3.16 Verification Report Auditability Implementation

> Status: Accepted / Completed

This delivery train implements deterministic report fingerprints, offline semantic
comparison, and stable CLI inspection without network access or repository mutation.

## Security boundary

The SHA-256 fingerprint is an equality aid. It is not a signature, trust decision,
authentication mechanism, authorization grant, or proof of provenance.

## Delivery

- v1.3.14: canonical UTF-8 report fingerprint.
- v1.3.15: stateless semantic comparison with stable field paths.
- v1.3.16: `report fingerprint` and `report compare` CLI commands.
