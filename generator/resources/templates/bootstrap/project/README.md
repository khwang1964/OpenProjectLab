## 開始使用

1. 編輯 `course.yaml`。
2. 使用 OPL CLI 建立課程與週次教材。
3. 將教材文件放入 `weeks/`。
4. 將圖片、圖表與其他素材放入 `assets/`。
5. 在 `docs/` 維護架構與教學文件。
