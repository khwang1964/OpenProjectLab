---

## 1. Purpose

GA.7 converts the already-verified stable repository and artifact state into
the immutable public `v1.0.0` release identity.

GA.7 owns creation and publication identity.

GA.7 does not own Formal GA Acceptance.

The publication chain must preserve one coherent relationship:

```text
Approved GA publication commit
        ↓
Annotated v1.0.0 tag
        ↓
Exact GA wheel / sdist / checksum manifest
        ↓
Draft stable GitHub Release
        ↓
Published stable GitHub Release
        ↓
Post-publication identity re-read
```

Any mismatch blocks completion.

---

## 2. Governing Decision

GA.7 is fail-closed.

The public stable release is valid only when all identity layers describe the
same `1.0.0` release.

Required stable identity:

```text
Package version
    1.0.0

Human-facing tag
    v1.0.0

GitHub Release prerelease
    false
```

The stable release must not reuse or mutate `v1.0.0-rc.1`.

## 5. Approved Publication Commit

GA.7 must explicitly record one approved GA publication commit.

It must be:

- a full lowercase 40-character Git SHA;
- reachable from synchronized `main`;
- the source of the final GA wheel and sdist;
- the exact target of the `v1.0.0` annotated tag;
- the target commit of the GitHub Release.

The approved publication commit is immutable evidence once the stable release is
published.

---

## 6. Fresh Final GA Build

Final public artifacts must be freshly built from the approved publication
commit.

Required sequence:

```text
clean dist/build metadata
        ↓
python -m build
        ↓
python -m twine check dist/*
        ↓
verify exact wheel / sdist set
        ↓
generate BOM-free SHA256SUMS.txt
        ↓
verify exact checksum coverage
```

Artifacts produced from a dirty tree, stale commit, RC source, or earlier GA
candidate commit do not satisfy final publication evidence.

---

## 7. Exact Published Asset Set

The final GitHub Release must publish exactly:

```text
openprojectlab-1.0.0-py3-none-any.whl
openprojectlab-1.0.0.tar.gz
SHA256SUMS.txt
```

No RC artifact may be present.

No stale distribution may be present.

No second wheel, second sdist, or unrelated file may satisfy the canonical GA
publication set.

---

## 8. SHA-256 Publication Identity

The final wheel and sdist digests must be computed from the exact bytes uploaded
to GitHub Release.

The checksum manifest must:

- contain exactly the wheel and sdist entries;
- contain valid lowercase 64-character SHA-256 values;
- match recomputed artifact bytes exactly;
- contain no UTF-8 BOM;
- contain no RC entry;
- contain no stale extra entry.

The GitHub Release asset digest for each artifact, when exposed by GitHub, must
agree with the verified local SHA-256 identity.

Any digest mismatch blocks publication completion.

---

## 9. Annotated Stable Tag Contract

GA.7 must create:

```text
v1.0.0
```

as an annotated Git tag.

The remote tag must be pushed exactly once for the approved stable identity.

Required verification:

```text
remote v1.0.0 annotated tag exists
peeled v1.0.0 target == approved GA publication commit
```

The tag must never be retargeted after publication.

If the tag points to the wrong commit, GA.7 stops and the release identity must
not be silently repaired by moving the published tag.

---

## 10. Draft-first GitHub Release Contract

The stable GitHub Release must be created draft-first.

Initial state:

```text
tag        v1.0.0
draft      true
prerelease false
```

Before publication, verify:

- release tag is `v1.0.0`;
- target commit is the approved publication commit;
- `draft == true`;
- `prerelease == false`;
- exact asset membership;
- artifact digests;
- checksum manifest;
- stable release name / identity.

Only after draft identity verification passes may the Release be published.

---

## 11. Stable Publication Contract

Final published state must be:

```text
tag        v1.0.0
draft      false
prerelease false
```

The published asset bytes must be the exact verified bytes from the approved
publication source.

GA.7 must not overwrite or replace published asset bytes under the same stable
identity.

---

## 12. Post-publication Identity Re-read

Publication completion requires a fresh re-read from GitHub after publication.

Required post-publication evidence:

```text
remote annotated tag exists
peeled tag target == approved publication commit
GitHub Release tag == v1.0.0
GitHub Release target == approved publication commit
draft == false
prerelease == false
exact asset set == wheel + sdist + SHA256SUMS.txt
published artifact digests == verified digests
```

Local assumptions are insufficient after publication.

---

## 13. RC Immutability Boundary

The accepted RC remains immutable historical publication evidence:

```text
Package version
    1.0.0rc1

Tag
    v1.0.0-rc.1
```

GA.7 must not:

- move `v1.0.0-rc.1`;
- replace RC asset bytes;
- rewrite RC release classification;
- reinterpret RC source commit as the GA publication commit.

GA creates a new stable identity.

---

## 14. Failure / Abort Policy

GA.7 must stop before publication when any of the following is detected:

| Failure | Required response |
|---|---|
| Dirty publication source | Clean / restart |
| Source SHA mismatch | Rebuild |
| Wrong version | Stop |
| Wrong wheel/sdist metadata | Stop |
| Checksum mismatch | Stop |
| Wrong tag target | Stop |
| Existing conflicting `v1.0.0` tag | Stop |
| Stable Release marked prerelease | Stop |
| Draft asset mismatch | Stop |
| Published asset mismatch | Stop |
| Post-publication identity mismatch | Record blocker; do not retarget silently |

No later passing check may erase an unresolved publication identity failure.
