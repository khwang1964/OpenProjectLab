# v1.3.6 Deterministic Verification I/O Contracts — Design Baseline

> Status: Accepted / Completed

## In scope

- strict versioned request and report JSON schemas
- exact validation and unknown-key rejection
- canonical deterministic JSON encoding
- deterministic human-readable report rendering
- preservation of every structured finding category
- fixture-based design-contract tests

## Out of scope

- production implementation
- CLI, public SDK, network protocol, plugin, or entry point
- discovery, inference, coercion, migration, repair, persistence, or publication
- test execution, arbitrary subprocesses, and Git/GitHub mutation
