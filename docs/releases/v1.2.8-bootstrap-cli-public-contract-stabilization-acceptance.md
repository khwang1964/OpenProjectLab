## Accepted contract

The v1.2.8 design fixes the proposed public Bootstrap CLI parsing,
normalization, exit-status, output-channel, validation-failure, deterministic
evidence, compatibility, and safety boundaries. It does not itself promote or
implement production behavior.

## Preserved boundaries

- The v1.2.7 experimental opt-in remains preserved until an independent
  implementation slice is reviewed and accepted.
- Legacy no-opt-in behavior remains unchanged.
- SDK exposure, JSON output, plugins, remote execution, repair, retry,
  rollback, and advanced lifecycle controls remain deferred.
- Production stabilization remains Not Started.
