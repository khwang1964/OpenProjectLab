## Accepted design scope

The `opl.bootstrap/1.0` JSON interchange design is accepted with a closed envelope,
canonical deterministic encoding, strict fail-closed decoding, immutable typed DTOs,
authoritative evidence arrays, inert lexical paths, and non-executing deserialization.

## Preserved boundaries

Deserialization remains non-executing and performs no filesystem, plugin, CLI, network,
repair, retry, or rollback operation. Binary formats, streaming, schema migration,
signing, encryption, remote execution, async transport, and plugin payload extensions
remain deferred.
