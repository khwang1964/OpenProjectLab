實作策略

不要一次把五個模組全部補完。建議每個模組形成一個小循環：

讀取模組
→ 列出公開行為
→ 補 happy path
→ 補 error path
→ 執行單檔 coverage
→ 重構 production code
→ 執行完整測試
→ commit

單一模組測試：

python -m pytest tests/core/test_filesystem.py -v

查看指定模組 coverage：

python -m pytest `
  tests/core/test_filesystem.py `
  --cov=generator.core.filesystem `
  --cov-report=term-missing

完整驗證：

python -m pytest `
  --cov=generator `
  --cov-report=term-missing `
  --cov-report=xml

注意拼字必須是：

--cov=generator

不是先前出現過的：

--cov=genertor
Coverage 門檻建議

不要直接從目前門檻跳回 80%，可分階段提升：

目前 baseline    先記錄實際值
第一階段         70%
第二階段         75%
五個模組完成     80%

在 pyproject.toml 可設定：

[tool.coverage.run]
branch = true
source = ["generator"]

[tool.coverage.report]
show_missing = true
skip_covered = true
fail_under = 80

開發期間如果尚未達到 80%，先暫時設定：

fail_under = 70

每完成一批測試再提高，避免 CI 長期紅燈而失去品質閘門的意義。
