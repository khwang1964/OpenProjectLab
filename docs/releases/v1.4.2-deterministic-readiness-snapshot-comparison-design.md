# v1.4.2 Deterministic Readiness Snapshot Comparison Design

> Status: Proposed / Pending design review

## Delivery slice

- Define stable readiness comparison categories and findings.
- Define fail-closed gate-specific regression detection.
- Define a bounded offline read-only comparison CLI.

## Accepted predecessors

The design consumes v1.4.0 canonical snapshots and v1.4.1 assembled evidence without changing
their schemas, readiness outcome rules, or authority boundaries.

## Proposed boundary

Two explicitly named canonical snapshots may be compared. The operation does not infer Git
ancestry, collect evidence, evaluate release authorization, or promote compatibility.
Production implementation is Not Started.

## Review gates

- [ ] Comparison categories and findings are deterministic.
- [ ] Every readiness gate has explicit regression semantics.
- [ ] Mismatched or ambiguous evidence is `INCOMPARABLE`.
- [ ] CLI inputs and byte limits are bounded and explicit.
- [ ] Offline read-only and non-authorizing boundaries remain intact.
- [ ] Tests, roadmap, HISTORY, CHANGELOG, and Code Review Checklist agree.
- [ ] Separate Design Acceptance follows merge verification.
