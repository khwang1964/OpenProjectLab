# v1.3.20-v1.3.22 Audit Bundle Schema Evolution Design Train

> Status: Accepted / Completed

## Delivery train

- v1.3.20 defines explicit audit-bundle schema compatibility classification.
- v1.3.21 defines deterministic, offline, non-executing migration planning.
- v1.3.22 defines stable compatibility and migration-preview CLI contracts.

## Accepted predecessor

The train builds on the terminally accepted v1.3.17-v1.3.19 canonical audit bundle,
offline validator, and stable bundle CLI. It does not revise that accepted schema or
reinterpret its SHA-256 equality aids as trust evidence.

## Deferred work

Migration execution, bundle rewriting, output artifacts, archives, signing, trust,
provenance, network access, remote publication, and repository mutation remain
deferred. Production implementation is Not Started.

## Review gates

- [ ] Architecture and release baseline agree on exact immutable boundaries.
- [ ] Compatibility never guesses or implicitly accepts unknown schemas.
- [ ] Migration planning is deterministic, offline, and non-mutating.
- [ ] CLI preview cannot execute or persist a migration.
- [ ] Contract tests, roadmap, HISTORY, and CHANGELOG agree.
- [ ] A separate terminal Design Acceptance follows merge verification.
