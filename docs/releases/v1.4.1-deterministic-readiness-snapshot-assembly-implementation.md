# v1.4.1 Deterministic Readiness Snapshot Assembly Implementation

> Status: Implemented / Pending post-merge verification

## Production scope

- Strict canonical immutable `ReadinessEvidenceManifest`.
- Bounded input-root-contained evidence reader with traversal and symlink rejection.
- Deterministic revision-bound assembler with stable fail-closed findings.
- Offline read-only `release-evidence readiness assemble` CLI.

## Preserved boundary

Assembly produces evidence only. It does not evaluate or authorize release, access a network,
discover credentials, mutate a repository or version, create tags or artifacts, or publish.
