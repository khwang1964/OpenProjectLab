## 2. Accepted Candidate Scope

The candidate contains exactly these production AI CLI commands:

``` text
opl ai course
opl ai review
opl ai document
opl ai template
```

Acceptance covers deterministic Stable local-response execution, explicit
Experimental provider execution, injection-only provider composition,
fail-closed provider selection, exit-code 2 / stderr / no-success-output
failure behavior, non-mutating filesystem/repository behavior, bilingual
EN/zh-TW documentation parity, and production registration of the exact
four-command inventory.

## 3. Preserved and Deferred Boundaries

This acceptance does not add automatic SDK import, automatic credential
lookup, implicit provider selection, network fallback, chat, agents,
streaming, tool calling, AI-mediated repository mutation, credential
persistence, or Formal v1.1 Acceptance.
